# Проверка пакета тех1

Проверено 27 октября 2026 года на локальной сборке из ветки feat/tech1-adaptive-journey. Это проверка прототипа и событий; банковский A/B-тест не проводился.

## Автоматические проверки

- 39 тестов Node.js: правила, все 72 сочетания профиля, канонические тексты, жизненный цикл черновика, размещение обучения.
- Проверка синтаксиса всех исполняемых JavaScript-файлов.
- Локальные ресурсы и отсутствие сетевых API; конфигурация Vercel и CSP.
- 14 из 14 контекстных сценариев приёмки. Сравнение стратегий остаётся проверкой требований, не оценкой бизнес-эффекта.
- Верификация выгрузки UI: один уникальный старт, одно продолжение, одна отправка, один показ помощи; ID и длительность согласованы, значения полей не экспортированы.

Команды из корня:

```sh
npm test
npm run check
node scripts/check-static.cjs
node scripts/compare-strategies.cjs
node scripts/check-journey-events.cjs docs/tech1/events-demo.json
npm run build
```

## Что изменилось

Раньше повторное открытие создавало новое событие начала, помощь после ввода одного поля не срабатывала, ввод терялся при смене клиента, а признак просмотра помощи мог относиться к другой заявке. Теперь у каждого локального черновика свой ID, первое начало, поля, счётчик возвратов и признаки помощи/звонка. Одна отправка учитывается один раз. Фоновая вкладка не накапливает простой для К5. Высота окна формы не меняется при показе помощи, основные действия остаются на месте.

Все пять групп правок координатора от 27.10 19:07 включены: таблица данных без конфликтующих чисел; убраны служебные пометки и статус черновика; неизвестная роль направляется к КМ; «Было» различается для клиентов 2/3; видны расшифровка кодов и подписи сегментов/гипотез.

## Границы готовности

Действия локальные: сообщения, звонки и банковские заявки не отправляются, CRM не подключена. Подтверждение прав и согласий условное. Черновики в памяти вкладки не заменяют банковское хранение; перезагрузка страницы начинает новый локальный проход, отметка показанной помощи сохраняется до конца сессии вкладки или явного сброса демо.

Публичный Vercel-сайт был размещён отдельно прямой загрузкой, автоматическая синхронизация GitHub не подключена. Эта QA относится к подготовленной сборке; соответствие публичной версии необходимо сверять после её повторной публикации. Не заявляем, что одна запись в GitHub обновляет Vercel.

Документ не подтверждает готовность интеграции банка, юридическое согласование динамического варианта текста или статистическую значимость Г4. Утверждённый исходный текст двух полей не изменён; вариант для одного оставшегося поля описан как новое дополнение.
